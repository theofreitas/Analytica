🎲 3. Modelo Binomial (Grupos Homogêneos)

🎯 Quando Usar

✓ N indivíduos de MESMA IDADE
✓ Queremos saber: "Quantos (k) satisfazem um evento?"
✓ Exemplos: quantos sobrevivem? quantos morrem?

📊 Variável Aleatória

Sₙ = número de sucessos
Sₙ ~ Binomial(N, Prob)

Prob = probabilidade individual do evento
Exemplos: ₙpₓ (sobreviver) ou ₙqₓ (morrer)
📐 FÓRMULA BINOMIAL:
P(Sₙ = k) = [N! / (k!(N-k)!)] × (Prob)ᵏ × (1-Prob)ᴺ⁻ᵏ
onde: N! / (k!(N-k)!) = combinação "N escolhe k" = C(N,k)
Média e Variância da Binomial:
• Média (μ) = N × Prob
• Variância (σ²) = N × Prob × (1 - Prob)
• Desvio Padrão (σ) = √(N × Prob × (1 - Prob))
Limitação: Para N muito grande (ex: N ≥ 100), os fatoriais ficam inviáveis de calcular!
Solução: Use o Teorema Central do Limite (TCL) → veja seção 5

🎯 4. Modelo Multinomial (Categorias Disjuntas)

🎯 Quando Usar

✓ Dividimos o grupo em 3 ou mais categorias
✓ As categorias formam uma PARTIÇÃO:
   → São disjuntas (sem interseção)
   → Cobrem todo o espaço amostral

Exemplo Visual de Partição

Categoria 1
Vivos após n anos
P₁ = ₙpₓ
Categoria 2
Mortos entre [0, 10]
P₂ = ₁₀qₓ
Categoria 3
Mortos após 10 anos
P₃ = ₁₀pₓ × q₍ₓ₊₁₀₎
P₁ + P₂ + P₃ = 1 ✓ (partição válida)
CUIDADO: Não pode haver interseção entre os intervalos de tempo ou idades!
Exemplo ERRADO: [0-10] e [5-15] (se sobrepõem!)
Exemplo CERTO: [0-10) e [10-20) (disjuntos!)
📐 FÓRMULA MULTINOMIAL:
P(Y = y) = [N! / (∏ yⱼ!)] × ∏ Pⱼʸʲ
onde:
• yⱼ = número de indivíduos na categoria j
• Pⱼ = probabilidade individual de estar na categoria j
• ∑ yⱼ = N (total de indivíduos)
Exemplo Prático:
100 pessoas de 30 anos. Queremos: 60 vivas, 25 mortas [0-10], 15 mortas [10-20]
P = [100!/(60!×25!×15!)] × P₁⁶⁰ × P₂²⁵ × P₃¹⁵

📊 5. Teorema Central do Limite (TCL)

🎯 Quando Usar

✓ Quando N é MUITO GRANDE (ex: N ≥ 100)
✓ Calcular fatoriais gigantes é INVIÁVEL
✓ Solução: Aproximar Binomial por Normal!

Transformação Binomial → Normal

🎲
Sₙ ~ Binomial(N, p)
Difícil calcular
quando N é grande
→
📊
Sₙ ≈ Normal(μ, σ²)
Fácil calcular
usando tabela Z
📐 PARÂMETROS DA NORMAL:
μ = N × p
σ² = N × p × (1 - p)
σ = √(N × p × (1 - p))
⚠️ CORREÇÃO DE CONTINUIDADE - ESSENCIAL!
Ao passar de distribuição discreta (Binomial) para contínua (Normal), precisamos ajustar:
P(Sₙ ≤ a) ≈ P(Z ≤ (a + 0,5 - μ) / σ)
P(Sₙ ≥ a) ≈ P(Z ≥ (a - 0,5 - μ) / σ)
P(Sₙ = a) ≈ P((a - 0,5 - μ)/σ ≤ Z ≤ (a + 0,5 - μ)/σ)
Passo a passo para usar TCL:
  1. Calcule μ = N × p
  2. Calcule σ² = N × p × (1-p) e σ = √σ²
  3. Aplique a correção de continuidade (±0,5)
  4. Padronize: Z = (x - μ) / σ
  5. Consulte a tabela Normal padrão

📝 Guia de Resolução das Questões

Q1 Grupos Homogêneos com Função s(x)

📐 Função s(x) = (1 - x/98)^(2/3) 👥 Joint Life 👤 Last Survivor 🔀 Heterogêneo
Como Resolver:
  • Item (a) e (b): Use fórmulas de potência (idades iguais)
    • Item (a): "Todos sobrevivem" → ₙpₓ̲ₙ = (ₙpₓ)ᴺ
    • Calcule ₙpₓ = s(x+n) / s(x)
  • Item (c): Último sobrevivente (X̄)
    • Prob. individual de morrer no intervalo: ₙqₓ
    • Todos morrerem: (ₙqₓ)ᴺ
    • Pelo menos um viver: 1 - (ₙqₓ)ᴺ
  • Item (d): Grupo heterogêneo (idades diferentes)
    • Calcule ₙpₓᵢ para cada idade individualmente
    • Multiplique todos: ₙpₓ₁ × ₙpₓ₂ × ... × ₙpₓₙ

Q2 Uso da Tábua de Mortalidade

📊 Tábua (Cap. 4) 👥 Joint vs Last 🎯 Cenários Disjuntos
Como Resolver:
  • Item (c): "Todos viverem pelo menos +1 ano"
    • É o produtório de pₓ para cada idade
    • Para x=1,2,...,80: p₁ × p₂ × ... × p₈₀
    • Lembre: pₓ = lₓ₊₁ / lₓ (use a tábua)
  • Item (f): "Apenas um sobreviver"
    • Soma de 3 cenários disjuntos:
    • (A vive ∧ B morre ∧ C morre) +
    • (B vive ∧ A morre ∧ C morre) +
    • (C vive ∧ A morre ∧ B morre)
    • Cada termo: pₐ × qᵦ × qᴄ (e variações)

Q3 Expressões Algébricas

🎲 Binomial Lógica 🔄 Complementar
Como Resolver:
  • Estratégia: Expressar em termos de ₙpₓ individuais
  • Exemplo: "No máximo 3 vivos de 5"
    • Forma Direta: P(0) + P(1) + P(2) + P(3)
    • Forma Complementar: 1 - [P(4) + P(5)]
    • Escolha a forma com menos termos!
  • Use combinações: C(5,k) × (pₓ)ᵏ × (qₓ)⁵⁻ᵏ

Q4 Contagem e Multinomial

🎯 Multinomial 📊 TCL (N grande) 🔀 Grupos Mistos
Como Resolver:
  • Itens (a) e (b): Grupos mistos
    • Metade idade x, metade idade y
    • Calcule cada metade separadamente
    • Multiplique os resultados (independência)
  • Itens (c) a (g): Modelo Multinomial
    • Verifique se as faixas são disjuntas!
    • Defina P₁, P₂, P₃ (prob. de cada faixa)
    • Aplique: [N!/(y₁!×y₂!×y₃!)] × P₁^y₁ × P₂^y₂ × P₃^y₃
  • Item (h): N=500 é GRANDE!
    • Use TCL (não calcule fatorial!)
    • μ = N × ₙpₓ
    • σ² = N × ₙpₓ × ₙqₓ
    • Correção de continuidade: 100 → 99,5
    • Padronize e use tabela Z

Q5 Função Paramétrica s(x) = exp(-x²/3000)

📐 Função Exponencial 🎯 Multinomial 📊 TCL (N=180)
Como Resolver:
  • Diferença da Q4: Use s(x) em vez da tábua
  • Calcular probabilidades base:
    • ₙpₓ = s(x+n) / s(x)
    • Para faixa [a,b]: prob = s(x+a)/s(x) - s(x+b)/s(x)
  • Item (e): "Pelo menos 60 morrem em [40,59]"
    • N=180 é grande → use TCL
    • Calcule p = prob. individual de morrer em [40,59]
    • μ = 180 × p
    • σ = √(180 × p × (1-p))
    • P(X ≥ 60) com correção: Z = (59,5 - μ) / σ

Q6 Interpretação de Fórmula Complexa

🧮 Inclusão-Exclusão 🔍 Análise de Padrão
Como Resolver:
  • Observação: A fórmula lembra P(A∪B∪C...)
  • Padrão típico:
    • Termos somados: pares (2 vivos)
    • Termos subtraídos: trios (3 vivos)
    • Termos somados: quartetos (4 vivos)
  • Estratégia:
    • Teste com casos simples (2 ou 3 pessoas)
    • Verifique se representa "pelo menos k vivos"
    • Use lógica de conjuntos para confirmar

Q7 Engenharia Reversa (Encontrar ₂₅p₂₀)

🧮 Sistema de Equações 🔄 Isolamento de Variáveis
Como Resolver:
  • Dados: Probabilidades conjuntas conhecidas
    • Exemplo: ₁₀p₂₀:₃₀:₄₀ = 0,758
  • Relação fundamental:
    • ₁₀p₂₀:₃₀:₄₀ = ₁₀p₂₀ × ₁₀p₃₀ × ₁₀p₄₀
  • Estratégia:
    1. Monte um sistema com as informações dadas
    2. Use as outras probabilidades conjuntas fornecidas
    3. Isole os termos que você precisa
    4. Combine equações para encontrar ₂₅p₂₀
  • Dica: Divida equações entre si para eliminar termos!
